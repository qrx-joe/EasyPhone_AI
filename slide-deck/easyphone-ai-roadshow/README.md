# EasyPhone AI 路演材料

## 文件

- `easyphone-ai-roadshow.pptx`：路演 PPT / BP 提交主文件。
- `source-easyphone-ai-roadshow.md`：PPT 内容源稿，可作为 BP 文案。
- `speaker-notes.md`：3 分钟路演讲稿。
- `outline.md`：8 页结构大纲。
- `generate_deck.py`：PPTX 生成脚本。

## 建议讲法

线上路演按 3 分钟控制：

1. 20 秒：项目定位。
2. 25 秒：老人和子女的痛点。
3. 25 秒：产品闭环。
4. 25 秒：核心差异，AI 知道什么时候不该回答。
5. 25 秒：低风险教、高风险停的流程。
6. 30 秒：Demo 三场景。
7. 25 秒：技术和安全兜底。
8. 25 秒：进展和下一步。
