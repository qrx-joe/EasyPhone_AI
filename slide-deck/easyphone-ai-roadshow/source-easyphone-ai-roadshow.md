# EasyPhone AI / 爸妈别急 路演 BP

> 线上路演时长：约 3 分钟  
> 用途：路演 PPT + BP 提交材料  
> 项目类型：AI Agent / AI Application / Elderly Digital Safety

## 一句话定位

EasyPhone AI 是给低识字中老年人的 AI 语音手机教练：普通手机问题一步一步教，遇到验证码、转账、陌生链接、屏幕共享等高风险场景时，先停下来，再找家人确认。

英文表达：

EasyPhone AI is an AI voice phone coach for low-literacy seniors. It guides safe phone tasks step by step, and stops risky actions before scams happen.

## 核心洞察

大多数 AI 助手都试图回答每一个问题。EasyPhone AI 的关键是：它知道什么时候不该继续回答。

普通问题，它一步一步教。危险问题，它先让老人停下来，再找家人确认。

## 用户痛点

智能手机已经成为生活入口，但对低识字或不熟悉数字设备的中老年人来说，它经常是一个高压系统。

老人端痛点：

- 不会打字，也不会准确搜索教程。
- 看不懂弹窗、按钮和复杂页面。
- 害怕点错，担心误删、扣费或被骗。
- 遇到验证码、转账、医保短信、陌生链接、屏幕共享时难以判断风险。
- 向子女求助时说不清页面和问题。

子女端痛点：

- 父母描述问题不清楚，电话指导效率低。
- 同一个问题反复教。
- 最担心父母误点链接、泄露验证码或被诱导转账。

## 解决方案

EasyPhone AI 不是替老人操作手机，也不是普通聊天机器人，而是一个有安全边界的 AI 语音手机教练。

核心流程：

1. 老人用语音或文字提出手机问题。
2. 系统判断问题类型和风险等级。
3. 低风险问题进入确认页，然后一步一步指导。
4. 高风险问题跳过教程，进入风险提醒页。
5. 系统生成家人求助卡，让子女快速看懂发生了什么。

## 产品能力

低风险场景：

- 微信没有声音。
- 手机字体太小。
- 手机设置类问题。
- 每次只展示一个步骤。
- 支持语音播报、没看到、点错了、找家人。

高风险场景：

- 验证码。
- 转账和退款。
- 陌生链接。
- 屏幕共享。
- 医保、社保异常短信。
- 系统停止教程，不提供危险操作步骤。

## 差异化

EasyPhone AI 的差异不是“AI 会回答手机问题”，而是：

- 先判断风险，再决定是否回答。
- 风险判断由本地规则兜底，AI 只是增强。
- 多关键词命中永远取最高风险等级。
- 高风险内容不进入普通教程。
- 求助卡不教老人把验证码、银行卡号、支付密码给出去。
- 第一版不读取短信、通讯录、定位，不做远程控制，不做金融/医保真实操作。

## Demo 场景

场景一：微信没有声音。

老人说：“微信没有声音了。”  
系统确认问题，判断低风险，进入分步教程。

场景二：手机字体太小。

老人说：“手机字太小，看不清。”  
系统用大字和语音引导进入字体设置。

场景三：医保短信和验证码。

老人说：“短信说医保卡不能用了，让我点链接，还要输验证码。”  
系统判断高风险，立即停止指导，提醒不要点链接、不要说验证码，并生成家人求助卡。

## 技术实现

技术栈：

- Next.js 16 + React 19 + TypeScript。
- Tailwind CSS 4。
- 浏览器 Web Speech API 语音输入。
- SpeechSynthesis 语音播报。
- 本地风险关键词规则 + MAX(level) 安全保险丝。
- 白名单教程库。
- 可选 DeepSeek AI 风险复检，仅在低风险输入上增强判断。
- Node.js 测试覆盖风险分类、路由、教程、求助卡等核心逻辑。

安全不变量：

- `buildRouteForInput()` 是唯一做高风险分流的入口。
- 风险命中永远取最高等级。
- 高风险不进入普通教程。
- 求助卡不指导用户泄露验证码、银行卡、支付密码。
