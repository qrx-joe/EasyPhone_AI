# EasyPhone AI 小红书图卡源内容

项目：面向海外华人长者的安全手机教练。

核心价值：普通手机问题一次只教一步；转账、OTP、陌生链接、屏幕共享等高风险场景先停止指导，再生成家人求助卡。

Google AI：Gemini 用于 LOW 输入的语义风险复检和家人求助说明改写。规则优先，AI 只能升级风险，异常时回退规则与模板。

首发市场：新加坡华人家庭。代表性场景包括英文银行短信、中英混合表达、WhatsApp 屏幕共享和异地家人协助。

工程证据：公开参赛分支、新版 Vercel Preview、211 项测试中 210 通过、0 失败、1 项 WCAG AAA 目标跳过，生产构建通过。

边界：没有真实用户规模和落地数据；截图多模态尚未实现；真实 Gemini 使用证据仍须由 AI Studio 或 API 联调补齐。
