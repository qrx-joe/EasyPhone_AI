# 产品逻辑说明

> OpenPrd 基线文档 · 权威 PRD 见 `docs/00-prd-cn-authoritative.md`,本文档为项目级基线摘要
> 最近更新:2026-06-10（更新 M5/M6 状态、demo 数量等过期点）

## 问题与目标

**问题**:老人遇到手机问题时,容易被骗(验证码/屏幕共享/转账)或者不会操作(微信没声音/字太小)。年轻人不在身边时,**老人独自面对风险**。

**目标**:做一个**手机教练**,让老人:
- 低风险问题 → 一步一步带做(语音/文字)
- 高风险问题 → **立刻停下来** + 生成家人求助卡

**MVP 成功标准**(docs/06 §2):
- 3 个 Demo 场景跑通:微信没声音、字太小、医保异常短信
- 高风险输入不进入教程
- 移动端可用,适老化(大按钮/大字号/单屏一动作)
- 不读短信/通讯录/位置(数据最小化)

## 用户故事

- 作为**老人**,我想用语音问"微信没声音了",看到一步一步的指导,直到问题解决
- 作为**老人**,我收到"短信让我输验证码",看到红色"停"页,知道这是诈骗
- 作为**老人**,我想一键把"遇到的诈骗"发给家人求助,不用打字描述
- 作为**家人**,我收到一张清楚的求助卡(我爸妈遇到什么事 + 我该做什么),能立刻帮上忙

## 功能范围

**MVP 已完成**(M0-M4):
- 项目初始化 + 目录结构
- 风险判断(规则兜底,~100 关键词,16 验收用例)
- 首页 + 语音/文本输入 + 3 个 demo 入口
- 低风险分步指导(2 个教程:微信没声音、字太小)
- 高风险中断 + 家人求助卡(可复制/模拟发送)
- Web Speech Recognition(语音输入)
- Web Speech Synthesis(教程步骤可念)
- 语速调节(慢/较慢/正常,持久化)
- Demo 直链路由(`/tutorial/demo?case=...`、`/risk-alert/demo?case=...`)

**P1 已完成**:语音识别、语音播报、复制求助卡、Demo 快捷入口、基础测试(80+)

**M5 已完成（2026-06-08，AI 风险复检）**:仅在 `base.level === 'low'` 时跑 DeepSeek recheck；env `ENABLE_AI_RISK_RECHECK` 默认关。详见 `docs/basic/backend-structure.md` "API 接入面" 段。**注意**：M5 接的是"AI 复检"，不是"AI 替规则判断"——安全主防线仍是规则 + `MAX(level)` 保险丝。

**M6 已完成（2026-06-08）**:Vercel 部署 `https://easy-phone-ai.vercel.app`、4 个 demo 直链跑通、Demo 脚本与录屏就位。详见 `docs/01-to-do.md` §9。

**明确不做**(P3):
- 真实微信/短信/通讯录读取
- 远程控制
- 支付/医保/金融真实操作
- Android 无障碍自动操作

## 验收标准

- 老人能语音说"微信没声音",**5 步**走完
- 老人打字"短信让我输验证码",**绝不能**进入教程,直接看到红色"停"页
- 求助卡能用剪贴板复制,内容包含「事件 + 建议 + 风险等级」
- 移动竖屏(375px)所有按钮 min-h ≥ 64px,字号 ≥ text-xl(20px+)
- 80+ 单测通过,TypeScript 严格模式无报错,生产构建成功

## 维护规则

- 需求边界、用户故事、验收标准变化后,必须更新本文件 + `docs/00-prd-cn-authoritative.md`
- 加新功能前先回答 [docs/05 §1](docs/05-project-standards.md) 的 4 个问题(服务闭环/降低风险/不增加负担/不引入隐私风险)
- 跑 `openprd run . --verify` 确认 PRD 与代码对齐
