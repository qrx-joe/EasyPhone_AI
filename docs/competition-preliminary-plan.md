## 一、迭代策略

**基于现有 EasyPhone AI 项目做「实质性版本迭代」，而非从零搭建。**

理由：
1. 现有项目已覆盖核心功能（语音问答、分步教程、反诈提醒、语音播报、适老化设计），与比赛方向高度重合
2. 比赛规则明确允许已有作品的「实质性版本迭代」
3. 时间紧迫（2 天），从零搭建风险高

## 二、核心迭代内容（3 项实质性改动）

### ✅ 迭代 1：三种无障碍模式切换（P0）

**目标：** 实现「标准 / 老年 / 简约」三种模式，一键切换，持久化保存。

**模式定义：**

| 模式 | 基准字号 | 对比强度 | 界面元素 | 适用人群 |
|---|---|---|---|---|
| 标准 | 18px | 普通（现有） | 完整导航 + 装饰元素 | 视力正常的老年人 |
| 老年 | 26px（大字） | 高对比度 | 简化装饰，突出主按钮 | 视力较差、老花眼 |
| 简约 | 22px | 普通 | 极简界面，仅核心功能 | 认知障碍、注意力不集中 |

**技术实现：**
- 通过 CSS 变量 + `data-mode` 属性控制全局样式
- 模式切换组件放在所有页面的右上角（固定悬浮）
- 用 localStorage 持久化用户选择，下次访问自动应用
- 修改 `globals.css`，为每种模式定义 CSS 变量集
- 封装 `useAccessibilityMode` hook 管理模式状态

**改动文件：**
- `src/app/globals.css` — 新增三种模式的 CSS 变量
- `src/app/layout.tsx` — 注入模式 class / data-attribute
- `src/components/a11y/mode-toggle.tsx` — 新建：模式切换组件
- `src/lib/a11y/use-mode.ts` — 新建：模式管理 hook

---

### ✅ 迭代 2：字号与对比度精细调节（P1）

**目标：** 在「老年模式」基础上，提供字号滑块和对比度开关，满足个性化需求。

**功能：**
- 字号调节滑块：范围 18px ~ 32px，步进 2px
- 高对比度开关：黑底黄字 / 白底黑字两套高对比方案
- 所有调节即时生效，持久化保存

**改动文件：**
- `src/components/a11y/font-size-slider.tsx` — 新建：字号滑块
- `src/components/a11y/contrast-toggle.tsx` — 新建：对比度开关
- `src/lib/a11y/use-mode.ts` — 扩展：支持字号、对比度独立调节
- `src/app/globals.css` — 扩展高对比度变量

## 六、验证标准

1. **功能可用：** 三种模式切换流畅，字号/对比度调节即时生效
2. **持久化：** 刷新页面后设置保留
3. **对比度合规：** 老年模式 + 高对比度下，正文对比度 ≥ 7:1（WCAG AAA）
4. **无回归：** 现有核心流程（提问→教程/风险提醒）不受影响
5. **移动端适配：** 手机端正常使用
