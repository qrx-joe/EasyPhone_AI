# EasyPhone AI 权威中文 PRD

> 项目副名：爸妈别急
> 版本：v1.0
> 状态：开发引用版
> 更新日期：2026-06-04

## 1. 一句话定位

EasyPhone AI 是一个给低识字中老年人的 AI 语音手机教练：普通手机问题一步一步教，遇到验证码、转账、陌生链接、屏幕共享等高风险场景时，先停下来，再找家人确认。

## 2. 核心判断

EasyPhone AI 的价值不是“AI 会回答手机问题”，而是：

> AI 知道什么时候应该一步一步教，也知道什么时候必须停下来。

这让它区别于普通聊天机器人、教程 App、远程控制工具和反诈宣传页。

## 3. 用户与痛点

### 3.1 核心用户

低识字或不熟悉数字设备的中老年人，重点是 60 岁以上用户。

他们通常：

- 会接打电话、微信语音、刷短视频。
- 不擅长打字、搜索、阅读长教程。
- 看不懂弹窗、权限、验证码、自动扣费等概念。
- 遇到陌生链接、转账、屏幕共享时容易慌。

### 3.2 次级用户

子女或家庭里的远程技术支持者。

他们需要：

- 快速理解父母遇到的问题。
- 判断是否存在诈骗或资金风险。
- 减少电话里反复解释的成本。
- 在高风险场景中及时介入。

## 4. MVP 产品边界

### 4.1 必须做

1. 语音提问：老人按住按钮说出问题。
2. 问题理解：AI 将口语描述整理成明确问题。
3. 风险判断：识别低风险、中风险、高风险、极高风险。
4. 分步指导：低风险问题每次只教一步。
5. 风险中断：高风险问题不继续给操作步骤。
6. 家人求助单：把老人说不清的问题转成家人能看懂的信息。

### 4.2 第一版不做

- 不做远程控制。
- 不读取短信。
- 不读取通讯录。
- 不申请定位。
- 不自动保存原始语音。
- 不保存敏感截图。
- 不指导转账。
- 不指导输入验证码。
- 不指导下载陌生 App。
- 不做开放社区。
- 不做医保、社保、金融代办。

## 5. 核心流程

### 5.1 低风险流程

```text
老人语音提问
-> AI 转写并理解
-> 用户确认问题
-> 风险等级：低
-> 展示第 1 步
-> 用户点击“好了”
-> 展示下一步
```

示例输入：

```text
微信没有声音了。
```

示例输出：

```text
你是不是想解决：微信没有声音？
```

第 1 步：

```text
先打开微信。打开以后，点“好了”。
```

### 5.2 高风险流程

```text
老人语音提问
-> AI 转写并理解
-> 命中风险词或语义高风险
-> 停止普通指导
-> 播报风险提醒
-> 生成家人求助单
```

示例输入：

```text
短信说医保卡不能用了，让我点链接，还要输验证码。
```

示例提醒：

```text
先别急，这个可能有风险。
不要转账。
不要告诉别人验证码。
不要点陌生链接。
不要打开屏幕共享。
我可以帮你发给家人看看。
```

## 6. 风险分级

| 风险等级 | 场景 | 处理方式 |
|---|---|---|
| 低风险 | 字体太小、微信没声音、手机充不进电 | 正常分步指导 |
| 中风险 | 空间不足、权限、自动续费、账号设置 | 先提示注意事项，再谨慎指导 |
| 高风险 | 验证码、银行卡、陌生链接、医保异常、客服退款 | 停止教程，建议找家人确认 |
| 极高风险 | 转账、屏幕共享、远程控制、支付密码 | 不给任何操作步骤，只提醒停止 |

### 6.1 高风险关键词

- 验证码
- 银行卡
- 转账
- 汇款
- 陌生链接
- 二维码
- 屏幕共享
- 远程控制
- 支付密码
- 身份证
- 退款
- 贷款
- 投资
- 中奖
- 医保异常
- 社保异常
- 下载 App

### 6.2 安全原则

高风险识别宁可误报，也不能漏报。

只要规则判断或 AI 判断任一认为高风险，就必须停止普通教程。

## 7. 页面需求

### 7.1 首页

目标：老人 10 秒内明白“不会弄手机，可以按这里说话”。

元素：

- 项目名：爸妈别急。
- 副标题：不会弄手机，慢慢说，我一步一步教你。
- 主按钮：按住说话。
- 次按钮：找家人。
- 次按钮：听说明。

要求：

- 字大。
- 对比清晰。
- 按钮面积大。
- 无广告、无信息流、无复杂弹窗。

### 7.2 问题确认页

目标：确认 AI 是否理解正确。

按钮：

- 是的。
- 不是，重新说。
- 找家人。

### 7.3 分步指导页

目标：每次只关注一个动作。

元素：

- 当前第几步。
- 大字步骤。
- 播放语音。
- 好了。
- 没看到。
- 点错了。
- 找家人。

### 7.4 风险提醒页

目标：让老人立刻停止危险操作。

语气：冷静、坚定、不恐吓。

必须出现：

- 不要转账。
- 不要说验证码。
- 不要点陌生链接。
- 不要打开屏幕共享。
- 找家人确认。

### 7.5 家人求助单页

目标：把老人模糊表达转成子女可理解信息。

元素：

- 问题摘要。
- 风险等级。
- 建议动作。
- 复制按钮。
- 保存卡片按钮。
- 返回首页按钮。

## 8. 首批 Demo 场景

### 8.1 微信没有声音

- 风险：低。
- 展示重点：语音提问、问题确认、一步一步教。

### 8.2 手机字体太小

- 风险：低。
- 展示重点：适老化、大字、短句、没看到时换说法。

### 8.3 医保异常短信 / 验证码

- 风险：高。
- 展示重点：AI 不继续教危险操作，而是停下来并生成家人求助单。

## 9. AI Agent 输出格式

```json
{
  "category": "wechat_notification",
  "riskLevel": "low",
  "confirmedQuestion": "你是不是想解决：微信没有声音？",
  "shouldStop": false,
  "reason": "普通设置问题，不涉及钱、验证码或陌生链接。",
  "steps": [
    {
      "stepIndex": 1,
      "stepText": "先打开微信。",
      "voiceText": "先打开微信。打开以后，点好了。",
      "fallbackText": "微信是绿色图标，里面有两个白色小气泡。"
    }
  ],
  "riskWarning": "",
  "familyMessage": ""
}
```

## 10. AI 安全规则

AI 必须：

- 使用短句。
- 使用老人能听懂的话。
- 每次只给一步。
- 不使用专业术语。
- 用户说“没看到”时换一种说法。
- 用户说“点错了”时引导安全返回。
- 遇到高风险内容立即停止指导。

AI 绝不能：

- 指导转账。
- 指导输入验证码。
- 指导提供支付密码。
- 指导打开屏幕共享。
- 指导下载陌生 App。
- 指导点击陌生链接。
- 做金融、医疗、法律决定。

## 11. 推荐技术路线

MVP 推荐：

- 前端：Next.js + React + TypeScript。
- 样式：Tailwind CSS。
- 语音识别：浏览器 Web Speech API，必须有文本输入兜底。
- 语音播报：浏览器 SpeechSynthesis。
- 风险判断：本地规则词库 + LLM 分类。
- 教程库：本地白名单 JSON。
- 存储：localStorage 或内存模拟。
- 部署：Vercel 或 Cloudflare Pages。

后续可扩展：

- Supabase / PostgreSQL。
- 家人端账号。
- 截图理解。
- 方言 ASR。
- Android 无障碍辅助。

## 12. 成功标准

Demo 阶段成功标准：

- 用户 10 秒内理解首页用途。
- 三个 Demo 场景能跑通。
- 高风险场景不会进入普通教程。
- 每次只展示一个步骤。
- 家人求助单简洁清楚。
- 页面适合手机竖屏。

最关键指标：

> 高风险识别宁可多提醒，也不要漏提醒。

## 13. 最终范围提醒

不要把第一版做成“大而全的老人手机助手”。

第一版的胜负手只有一个：

> 普通问题一步一步教，危险问题先停下来。
