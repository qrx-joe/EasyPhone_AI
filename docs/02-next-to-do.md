## 本轮冲刺目标

在本地建立 EasyPhone AI 的 Web MVP 骨架，并跑通三个核心演示场景：

1. 低风险：微信没有声音。
2. 低风险：手机字体太小。
3. 高风险：医保异常短信、陌生链接、验证码。

## 执行顺序

### 1. 确认文档编码

- 状态：已完成初步处理。
- 已检查两份 PRD 的真实编码。
- 已将两份 PRD 用 UTF-8 重新保存，降低 Windows PowerShell 默认读取乱码的概率。
- 已新增 `00-prd-cn-authoritative.md` 作为开发引用版。

### 2. 选择并初始化技术栈

- 推荐栈：Next.js + TypeScript + Tailwind CSS。
- 包管理：必须使用 `uv` 仅适用于 Python；如果创建前端项目，按 Node 项目规范使用对应包管理器，但 Python 相关工作必须走 `uv`。
- 需要先确认是否要做纯前端 Demo，还是要接 AI API。

### 3. 建立核心数据结构

- `QuestionRecord`
- `TutorialStep`
- `HelpRequest`
- `RiskLevel`
- `AgentOutput`

### 4. 实现风险判断

- 先做规则兜底。
- 后续再接 LLM 分类。
- 原则：高风险宁可误报，也不能漏报。

### 6. 做最小测试
